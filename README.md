# NextMovie

## Vision

NextMovie is a cross-platform movie recommendation platform that helps users discover the best movie they haven't seen that they can stream right now.

The platform combines movie history, streaming availability, and personalized recommendations into one seamless experience.

## Platforms

- 🌐 Web
- 📱 iOS
- 🤖 Android

## Planned Features

- Letterboxd import
- Personalized recommendations
- Streaming service filtering
- AI-powered natural language search
- Watchlists
- User profiles
- Movie statistics
- Social features
